Pequeno projeto pessoal onde tento explorar os conhecimento adquiridos no primeiro período de Engenharia de Software. Este programa é um algoritmo simples de geração de células, onde podemos acompanhar
suas evoluções de acordo com as gerações que se passam. 

O algoritmo funciona de duas maneiras, criação manual das células, onde você escolhe o local das células, e criação aleatória das células.
